Learn about writing well-formed user stories for business-level requirements - [article](https://www.easyagile.com/blog/how-to-write-good-user-stories-in-agile-software-development). Read section 3.3.3 "INVEST: criteria for \"good\" backlog items" of the [IREB RE@Agile Handbook](https://cpre.ireb.org/en/downloads-and-resources/downloads#cpre-re-agile-handbook).
1. Based on the requirements gathered for BrightStar, write 3 user stories.
2. Add acceptance criteria using [Gherkin Format](https://cucumber.io/docs/terms/user-story/#acceptance-criteria-using-cucumber-language) to each user story.
3. Review and refine your user stories using the INVEST criteria.
