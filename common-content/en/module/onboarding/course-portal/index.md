Log in to your [Course Portal](https://portal.codeyourfuture.io/). This is a different portal to the one you used to complete ITD. We are rolling out a new portal for ITP, and you're the first cohort to use it. That means there may be some bugs - sorry! If something seems confusing or broken, please let us know!

On the Course Portal you should be able to see what tasks are expected of you each week, and the status of each task. Some will update automatically (e.g. pull requests will get marked as "reviewed" or "complete"). Others, you will need to tick off when you've completed them.

At {{<our-name>}}, weeks start on Tuesday. You are expected to do each task during the week it was set. So the deadline for each task is the next Monday.

Sometimes you will get through things quickly - if this happens, celebrate, and start working on the next week's work.

Sometimes you will need a bit more time. That's ok, but we need to be careful. If you fall more than two weeks behind, we may ask you to leave the course. If you notice yourself falling behind, talk to a member of the education team about it. The sooner we talk about it, the sooner we can try to do something about i.
